# Free design-partner program

AfterMerge is looking for five teams that regularly merge pull requests from
coding agents such as GitHub Copilot, Codex, Devin, or an internal bot.

## Good fit

- At least ten agent-authored pull requests per month.
- GitHub is the source of truth for engineering work.
- The team wants to understand post-merge rework without uploading prompts or
  source code to another service.
- An engineering lead can spend fifteen minutes reviewing the first report.

## What the team receives

- A read-only weekly GitHub Actions report.
- 7-day and 30-day survival and neutral turnover measurements.
- Per-file and category breakdowns.
- Explicit-revert and commit-context signals.
- Direct influence over the first paid cross-repository dashboard.

## Privacy and cost

The Action runs inside the repository's GitHub runner. It uses Git history and
pull-request metadata, requires read-only permissions, and does not need an LLM.
The design-partner version is free.
